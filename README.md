Papyrite is intended to be a NoSQL alternative for embedded database, i.e., instead of using a server, or DB cluster, it stores data locally on host files. It is completely implemented in Rust with C bindings.

# Planned features

1. Embedded local database
2. Document-oriented storage
3. Multiple collections
4. CRUD by primary key
5. Secondary indexes on selected fields
6. Basic transactions
7. Crash recovery
8. Basic compaction
9. C ABI for core operations
10. Test harness
